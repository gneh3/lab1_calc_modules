# Лабораторная работа №1: CLI Калькулятор и Конвертер величин (`toolkit`)

Консольное приложение на Python, предоставляющее функционал математического калькулятора на основе обратной польской записи (RPN) и универсального конвертера физических величин (длина, масса, температура).

## Функциональные возможности

### 1. Калькулятор (`calc`)
- **Алгоритм RPN:** Разбор выражений алгоритмом сортировочной станции (Shunting-yard) и вычисление через стек.
- **Поддерживаемые операции:** Сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`), целочисленное деление (`//`), остаток от деления (`%`).
- **Унарные операции:** Поддержка унарного плюса и минуса (например, `-2 * -3`).
- **Скобки:** Вычисление сложных выражений со скобками произвольной вложенности.
- **Высокая точность:** Все вычисления выполняются с использованием модуля `Decimal` (без погрешностей `float`).
- **Разделители:** Поддержка как точки (`.`), так и запятой (`,`) в качестве десятичного разделителя.

### 2. Конвертер величин (`convert`)
- **Длина:** Метры (`m`), километры (`km`), сантиметры (`cm`), миллиметры (`mm`).
- **Масса:** Граммы (`g`), килограммы (`kg`), миллиграммы (`mg`).
- **Температура:** Градусы Цельсия (`C`), Фаренгейта (`F`), Кельвины (`K`).
- **Валидация:** Проверка на несовместимые категории (например, масса в длину), неизвестные единицы и недопустимые физические значения (ниже абсолютного нуля < 0 K).

## Требования к коду и архитектура

В проекте строго соблюдены требования к оформлению:
- Именование переменных, функций и модулей в стиле `snake_case`.
- Именование классов в стиле `PascalCase`.
- Вынос констант в модуль `constants.py` в стиле `UPPER_CASE`.
- Кастомная иерархия исключений с базовым классом `ToolkitBaseError` в `errors.py`.

## Установка и настройка

1. **Клонируйте репозиторий и перейдите в корень проекта:**
   ```bash
   git clone <url-репозитория>
   cd lab1_calc_modules
   ```

2. **Создайте и активируйте виртуальное окружение:**
   - С использованием `uv`:


## Примеры использования CLI

Запуск приложения осуществляется через модуль `toolkit`:

### Калькулятор
```bash
# Базовые вычисления
python -m toolkit calc "2 + 3 * 4"

# Унарный минус и скобки
python -m toolkit calc "-(5 * 3) + 3"

# Целочисленное деление и остаток
python -m toolkit calc "10 // 3 + 10 % 3"

# Использование запятой в числах
python -m toolkit calc "2,5 * (4 - 2)"
```

### Конвертер
```bash
# Конвертация длины
python -m toolkit convert 1000 --from mm --to m

# Конвертация массы
python -m toolkit convert 1.5 --from kg --to g

# Конвертация температуры
python -m toolkit convert 0 --from C --to F
```

## Обработка ошибок

При возникновении ошибок (деление на ноль, синтаксическая ошибка выражения, несовместимые единицы) приложение отправляет понятное сообщение в поток `sys.stderr` и завершает работу с **кодом 2**:

- `CalculatorError`: Несогласованные скобки, ошибка синтаксиса или деление на ноль.
- `ConverterError`: Неизвестные или несовместимые единицы измерения, температура ниже абсолютного нуля.
